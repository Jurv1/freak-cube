# Монстрики

Выгружено из `src/shared/GameData.luau`. Источник правды — этот модуль: меняешь имя или рецепт там — обнови таблицу.

Доход — монет в секунду на 1-м уровне (умножается на уровень, у золотого ещё ×5). Порядок — как в книге рецептов в игре.

Боевые статы, основной тип, подтип и скиллы тех же зверьков — в `battles.md`. С этапа 3б код считает бои по правилам версии 2, и таблицы `battles.md` совпадают с `GameData`; прокачки характеристик в коде ещё нет (этап 3в). Время выпечки в таблице — для печи 1-го уровня; по дизайну печи старших уровней делят его на свою скорость (`design.md`, «Печи»).
